# Placement Prep Tracker

Static 56-day placement tracker built from Placement_Prep_Daily_Checklist.pdf.

Features: 8-week dashboard, start date/current-day highlighting, 56 daily checklists, completion tracking, 28-company tracker with the PDF's last-season deadlines and CTC values, company status/notes, mistake log, JSON backup export, responsive layout, browser localStorage.

The company deadlines are explicitly last-season (2025–26) values from the supplied PDF; current portal dates should be checked before acting on them.
